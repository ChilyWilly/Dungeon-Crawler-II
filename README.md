# Dungeon-Crawler-II
A dungeon crawler that will hopefully work better and become an actual game.

This is the beginning of a dungeon crawler game that I am making. Use the WASD keys to move, and the left mouse button to attack. If you hold the attack button, then the character will do a charged attack. Currently, the attacks do nothing but play animations. Click the shift key to toggle debug mode, and if you click space near a chest, then you will open it. The enemies deal damage and so do the spikes.
